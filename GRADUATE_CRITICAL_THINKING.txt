QUESTION 03 - ARCHITECTURE DEFENSE
Prompt: Build the major content frame with named Grid areas and the review metadata
with Flexbox. Record the same page at exactly 700px and 480px, then explain which
relationship belongs to Grid and which belongs to Flexbox using measured overflow,
computed dimensions, and alignment results.

Suggested answer (adapt to your actual browser evidence):
I used CSS Grid for the high-level relationship between the review content and the
overview sidebar because these are two distinct page regions with a stable hierarchy.
The .review-frame declares the named areas "reviews" and "overview". At the narrow
breakpoint, the areas are placed in one column, with reviews first and overview second.
This changes the page-level composition without changing the HTML order.

I used Flexbox for the rating strip and each review quote/critic row because those
components align items along one axis. The rating strip aligns the Rotten Tomatoes
icon, score, and review count; the quote row aligns the vote icon beside the quote.
Flexbox is appropriate here because the items need spacing and alignment, not a
two-dimensional page-region map.
